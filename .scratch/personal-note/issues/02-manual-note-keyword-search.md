# 02: Manual Note & Keyword Search

**What to build:** A user can create, edit, categorize, list, and search Notes from the web without LINE or AI being available.

**Blocked by:** 01: Foundation & Local Deployment

**Status:** ready-for-agent

- [ ] A Note can be created from the web with text and optional category.
- [ ] A Note without a category appears as `ยังไม่จัดหมวด`.
- [ ] Categories can be created, renamed, colored, and assigned to Notes.
- [ ] Notes can be edited and viewed with captured date and source metadata.
- [ ] Keyword search supports Note text, category, and date filters with pagination.
- [ ] Search still works when no AI provider is configured.
- [ ] Repository, API, and UI tests cover empty states, invalid input, missing records, and successful search.
